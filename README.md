# Chennai-Metro-Rail
Chennai Metro Rail Dashboard using Power BI Built an interactive Power BI dashboard to analyze Chennai Metro passenger traffic, revenue trends, station performance, and operational efficiency using Power Query, DAX, and data visualization techniques.

**Project Description**
**Collected and transformed metro rail data using Power Query and Excel/CSV datasets.
**Performed data cleaning, preprocessing, and data modeling in Power BI.
**Created interactive dashboards to monitor passenger traffic, revenue, station performance, and train operations.
**Designed KPIs such as total passengers, peak travel hours, revenue generation, busiest routes, and monthly growth trends.
**Used DAX functions to calculate measures, trends, and comparative analysis.
**Implemented slicers, filters, and drill-through reports for user-friendly navigation.
**Visualized insights using bar charts, line charts, maps, pie charts, and KPI cards.
**Generated actionable insights to improve operational efficiency and passenger management.

**Tools & Technologies**
**Power BI
**Power Query
**DAX
**Excel / CSV
**Data Visualization

**Key Insights**
**Identified peak-hour passenger congestion patterns.
**Analyzed high-revenue metro stations and routes.
**Compared weekday vs weekend passenger trends.
**Tracked monthly growth in metro usage and revenue.
